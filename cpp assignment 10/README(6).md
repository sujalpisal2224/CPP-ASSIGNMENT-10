## Practical Title

Class Template and Function Template

## Problem Statement

Implement class templates and function templates in C++ to demonstrate generic programming and code reusability with different data types.

## Objectives

- To understand the concept of templates in C++.
- To implement a class template.
- To implement a function template.
- To perform operations on different data types.
- To understand generic programming and code reusability.

## Theory

Templates in C++ allow programmers to write generic code that works with different data types.

**Class Template:** A class template allows a class to operate on different data types. In this assignment, the `Calculator` class performs subtraction and division using integer and double values.

**Function Template:** A function template allows a single function to work with different data types. In this assignment, the `findMinimum()` function compares two values and returns the smaller value.

## Algorithm

1. Start the program.
2. Declare a class template named `Calculator`.
3. Define data members to store two values.
4. Create a constructor to initialize the values.
5. Define functions for subtraction and division.
6. Create objects using integer and double data types.
7. Define a function template named `findMinimum()`.
8. Display the results.
9. Stop the program.
